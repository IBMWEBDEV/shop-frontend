# ShopBD - Full Stack E-commerce Platform

ShopBD একটি আধুনিক ই-কমার্স অ্যাপ্লিকেশন যা React এবং Tailwind CSS ব্যবহার করে তৈরি করা হয়েছে।

## 🚀 ফিচারসমূহ
- রেসপন্সিভ ডিজাইন (মোবাইল ও ডেস্কটপ ফ্রেন্ডলি)
- প্রোডাক্ট ক্যাটাগরি এবং ফিল্টারিং
- ডায়নামিক শপিং কার্ট সিস্টেম
- লিকুইড এবং ক্লিন ইউজার ইন্টারফেস

## 🛠 টেকনোলজি স্ট্যাক
- **Frontend:** React.js (v19)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router Dom

## 💻 যেভাবে আপনার পিসিতে চালাবেন
১. রিপোজিটরি ক্লোন করুন:
   git clone https://github.com/your-username/ShopBD-Ecommerce.git

২. প্রোজেক্ট ফোল্ডারে যান:
   cd shopbd

৩. ডিপেন্ডেন্সি ইন্সটল করুন:
   npm install

৪. প্রোজেক্ট শুরু করুন:
   npm start
